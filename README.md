# Team Brain

Shared knowledge base that captures skills and learnings from Claude Code sessions.

## Setup

1. Clone/sync this directory to `~/team-brain/`
2. Copy the extraction skill: `cp extract-skill.md ~/.claude/skills/extract.md`
3. Open `viewer/index.html` in a browser to see the dashboard

## Usage

At the end of a Claude Code session, run `/extract` to capture skills and learnings.

## Data

- `data/skills.json` — who knows what
- `data/learnings.json` — tactical insights worth sharing
